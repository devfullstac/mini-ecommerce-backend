# Mini E-Commerce Backend (Node.js + Express + Sequelize)

## How to Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file in the root directory with:
   ```env
   PORT=3000
   JWT_SECRET=mon_secret_key_projet_2026
   ```
3. Start the server:
   ```bash
   node index.js
   ```
